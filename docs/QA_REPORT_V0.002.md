## 資料與安全

- JSON 只載入明確驗證後的音高、時間及必要 metadata；不執行程式，不把來源檔名寫入動態 HTML。
- 原音音高對應為音組層級；手動新增的獨立音組沒有來源秒數。原有組增減音高仍參考原本該組的來源片段。
- 匯入 JSON 不包含原始音檔；對照原音需另選同名音檔。以檔名及時間範圍核對，不宣稱已用 hash 驗證音訊內容。
- 每組最多 12 音、共 1,000 組，JSON 最多 2MB，歷史最多 100 步。
- 編輯結果只在記憶體；下載 JSON 可保存。重新整理會清除未下載結果，沒有雲端自動儲存。
- 更新沒有改動辨識演算法或宣稱真實場域正確率提升。和弦手動指定與自動多音辨識分開處理。
