# P142 版本紀錄

## V0.004 · 2026-11-08（臺灣時間）

- 音組間距四段選擇：最緊密、緊緻（預設）、標準、寬鬆，畫面及 SVG 下載同步。
- 以每組實際音符、和弦、變音記號及文字寬度換行，複雜和弦不再撐寬整張譜。
- 最後一行不拉開填滿；行間保留編號與拍數文字空間。
- 間距保存在瀏覽器偏好，不影響音高、拍數、播放速度、來源秒數及編輯歷史；JSON 格式不變。
- 46 項測試與 8 項 SDS 靜態檢查通過，維持 SBI-P-SDS v3.6。

## V0.003 · 2026-11-08（臺灣時間）

- 自動辨識只辨音高，所有音組拍數預設未設定，不從原音秒數推論拍數。
- 手動指定 ¼、½、1、1½、2、3、4 拍，和弦整組共用；可改回未設定。
- 譜面依拍數顯示符幹、符尾、空心音頭與附點，不加入拍號或小節。
- 30–240 BPM 試聽；未設定音組維持 0.65 秒間隔，支援混合播放。
- 拍數及 BPM 納入復原／重做、SVG 與 JSON schema 3；相容 schema 1、2。
- 39 項測試及 8 項 SDS 靜態檢查通過，維持純前端與 SBI-P-SDS v3.6。

## V0.002 · 2026-11-07

- 五線譜新增前後音組、同組和弦音、半音／八度按鈕與鍵盤操作。
- 個別音符刪除、空白譜重建、復原／重做（100 次）。
- JSON schema 2 保存與重新載入；相容 V0.001 schema 1，限制異常輸入並保護現有文件。
- 手動音組的原音時間為 null；載入同名原音檔可保留匯入的編輯結果。
- 和弦音頭與變音記號避讓；固定間隔、同組同時試聽；限制同時排程，減少長序列音訊資源占用。
- 採用已確認的中英文標語，版本及 cache busting 升至 V0.002，維持 SBI-P-SDS v3.6。

## V0.001 · 2026-10-30

- 首版：音檔匯入、片段選擇、開始／取消分析。
- 單音旋律與實驗多音模式；C2–C7。
- 依序呈現高低音譜表、音名及八度，不推論拍號與節奏。
- 音符、原音片段與虛擬鍵盤試聽；修正及刪除音高。
- SVG 五線譜與 JSON 資料下載連結。
- 自製合成範例、MP3 測試檔、SDS v3.6 文件與交付檢查。
