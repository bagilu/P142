## 使用與限制

小節線附於指定音組之後，刪掉該組最後一音也會移除該線，可復原。移動不覆寫既有線。不驗算每小節拍數，不加入拍號、休止符、反覆記號或自動分小節。線型不改變播放時值或插入停頓。長小節可跨行，但不會因此新增小節線。重新整理前仍須下載 JSON 保存。
